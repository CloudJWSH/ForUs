# Strategie-Dateien

Beispiele im offenen Format `pump-paper-strategy` (Version 1) aus dem Strategie-Labor der Website (`strategie.html`).
Eine Strategie enthält nur Regeln: Einstieg, Einsatz, Ausstieg, Grenzen und Ausführung. Sie kauft nichts.

- `strategy.schema.json`: JSON-Schema des Formats. `tools/check.py` prüft jede Datei hier dagegen.
- Änderungen am Format nur mit neuer `version`.

Änderungen: Version 1 (21.10.2026): erstes Format.
