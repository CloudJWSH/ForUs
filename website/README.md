# Pump Paper Website

Produktseite für die Chrome-Erweiterung Pump Paper (Papertrading auf pump.fun).

- Eine statische Seite: `index.html`, keine Build-Schritte, nur Google Fonts als externe Quelle.
- Icons kommen aus der Erweiterung (`icons/`).
- Lokal ansehen: `index.html` im Browser öffnen.
- Hosten: den Ordner `website/` auf GitHub Pages, Netlify, Vercel oder Cloudflare Pages ausliefern.

Offen: Download-Link für die Zip (Knopf zeigt „Download folgt in Kürze“).
